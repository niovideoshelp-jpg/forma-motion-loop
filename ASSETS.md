# Asset provenance

## Original imagery

The album covers were generated with the built-in image generation tool. A model version was not exposed by the tool. No claim is made that these used a model called GPT 2.5 Image.

## Cursor

Source: https://github.com/ful1e5/apple_cursor/blob/main/svg/left_ptr.svg

Open-source macOS-style pointer from ful1e5/apple_cursor, GPL-3.0. The source template's green/blue placeholder colors were changed to black/white, then rasterized for canvas performance. This is an open-source reproduction of the macOS pointer, not an asset extracted from a local Apple installation. License: public/assets/cursor-LICENSE.txt.
